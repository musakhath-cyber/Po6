# Procurement Basket Optimizer

Multi-supplier catalog ingestion, demand planning, and Mixed-Integer Linear Programming (MILP) basket cost minimization dashboard built with Python, SciPy (HiGHS solver), and Streamlit.

## Streamlit Cloud Deployment
1. Upload `app.py`, `requirements.txt`, `README.md`, and `.gitignore` to your GitHub repository root.
2. In Streamlit Cloud, set the main file path to `app.py`.
3. Deploy the application.
